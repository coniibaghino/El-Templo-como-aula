# El Templo como Aula

Sitio web del proyecto **"El Templo como Aula: un modelo de visitas guiadas en el Instituto Sagrado Corazón de Lanús"**, presentado al Concurso de Valoración Patrimonial de Cementerios, Templos y Lugares Sagrados 2026.

Propone un circuito de visitas guiadas por alumnos de nivel secundario, replicable en cualquier capilla escolar, para revalorizar el patrimonio del barrio y desarrollar las habilidades comunicativas de los estudiantes.

## Estructura

```
index.html        página única
css/style.css     estilos (variables de color y tipografía al inicio)
js/script.js      animaciones e interacción
img/              logos, fotos del circuito y folleto
```

Sitio estático, sin dependencias ni build: abrir `index.html` o servirlo con GitHub Pages.
